SECTION 1: BEFORE YOU BEGIN
================================================================

1.1 What You Need:
□ A computer with internet access
□ Google Workspace account (company-provided email)
□ Basic knowledge of Google Sheets and Forms
□ 30-60 minutes for initial setup
□ The files provided in this package

1.2 What This System Does:
- Tracks quality of teaching in Mathematics department
- Collects feedback from students
- Monitors exam and assessment quality
- Tracks research projects
- Shows real-time dashboard with quality metrics
- Sends automatic email reports

1.3 Who Will Use This:
- QC Team Members: Enter observation data
- Instructors: View their performance metrics
- Department Head: Monitor overall quality
- Students: Submit feedback

5.5 CONFIGURING YOUR SETTINGS
================================================================

Now you need to update the config.gs file with YOUR specific
information. This is very important!

-----------------------------------------------------------------
STEP 1: Open config.gs
-----------------------------------------------------------------
   a) Click on "config.gs" in the left sidebar
   b) The code appears in the editor

-----------------------------------------------------------------
STEP 2: Find Your Spreadsheet ID
-----------------------------------------------------------------
   a) Open your Google Sheet in another tab
   b) Look at the URL in your browser's address bar
   c) The URL looks like this:
   
      https://docs.google.com/spreadsheets/d/XXXXXXXXXXXXX/edit
                                             ↑↑↑↑↑↑↑↑↑↑↑↑↑
                                             THIS IS YOUR ID
   
   d) Copy the long string of letters and numbers between /d/ and /edit
   
   Example URL:
   https://docs.google.com/spreadsheets/d/1aBcDeFgHiJkLmNoPqRsTuVwXyZ/edit
   
   Your ID would be: 1aBcDeFgHiJkLmNoPqRsTuVwXyZ

-----------------------------------------------------------------
STEP 3: Update the Spreadsheet ID in config.gs
-----------------------------------------------------------------
   a) In config.gs, find this line (around line 15):
   
      const SPREADSHEET_ID = '[SPREADSHEET_ID]';
   
   b) Replace [SPREADSHEET_ID] with your actual ID
   c) Keep the quotes! It should look like:
   
      const SPREADSHEET_ID = '1aBcDeFgHiJkLmNoPqRsTuVwXyZ';

-----------------------------------------------------------------
STEP 4: Update Email Addresses
-----------------------------------------------------------------
   Find the EMAIL_CONFIG section (around line 30) and update:

   a) Find: QC_LEAD: '[QC_LEAD_EMAIL]'
      Replace with your QC Lead's email:
      QC_LEAD: 'john.smith@university.edu'

   b) Find: DEPARTMENT_HEAD: '[DEPARTMENT_HEAD_EMAIL]'
      Replace with your Department Head's email:
      DEPARTMENT_HEAD: 'jane.doe@university.edu'

   c) Find: IT_SUPPORT: '[IT_SUPPORT_EMAIL]'
      Replace with your IT Support email:
      IT_SUPPORT: 'it.help@university.edu'

-----------------------------------------------------------------
STEP 5: Update Backup Folder ID (Optional)
-----------------------------------------------------------------
   If you want automatic backups:
   
   a) Create a folder in Google Drive called "QC_Backups"
   b) Open that folder
   c) Look at the URL, copy the ID (similar to spreadsheet)
   d) Find this line in config.gs:
      BACKUP_FOLDER_ID: '[BACKUP_FOLDER_ID]'
   e) Replace with your folder ID

-----------------------------------------------------------------
STEP 6: Save Your Changes
-----------------------------------------------------------------
   a) Press Ctrl+S (Windows) or Cmd+S (Mac)
   b) Wait for save to complete

-----------------------------------------------------------------
EXAMPLE OF COMPLETED CONFIG:
-----------------------------------------------------------------

BEFORE:
   const SPREADSHEET_ID = '[SPREADSHEET_ID]';
   QC_LEAD: '[QC_LEAD_EMAIL]',
   DEPARTMENT_HEAD: '[DEPARTMENT_HEAD_EMAIL]',

AFTER:
   const SPREADSHEET_ID = '1aBcDeFgHiJkLmNoPqRsTuVwXyZ';

9.1 FORMS NOT SUBMITTING
================================================================

SYMPTOM: 
Clicking "Submit" does nothing, or you see an error.

2. Look for questions marked with red asterisk *
3. Make sure ALL required questions are answered
4. Look for red text saying "This is a required question"

-----------------------------------------------------------------
SOLUTION B: Check Internet Connection
-----------------------------------------------------------------
1. Open a new tab
2. Go to google.com
3. If it loads, internet is working
4. If not, check your WiFi/network connection

-----------------------------------------------------------------
SOLUTION C: Refresh and Try Again
-----------------------------------------------------------------
1. Copy any long text answers (so you don't lose them)
2. Press F5 or click Refresh
3. Fill out the form again
4. Try submitting

-----------------------------------------------------------------
SOLUTION D: Try Different Browser
-----------------------------------------------------------------
1. Open Google Chrome (recommended)
2. Go to the form link
3. Fill out and submit

-----------------------------------------------------------------
SOLUTION E: Clear Browser Cache
-----------------------------------------------------------------
1. Press Ctrl+Shift+Delete
2. Select "Cached images and files"
3. Click "Clear data"
4. Try the form again

-----------------------------------------------------------------

3. Wait 2 minutes
4. Open again and check

-----------------------------------------------------------------

2. Find the failed execution
3. Click to see error details
4. Note the error message

-----------------------------------------------------------------

FIX: Check SPREADSHEET_ID in config.gs is correct

ERROR: "Sheet not found"
FIX: Check sheet names match exactly (case-sensitive)

SECTION 13: FREQUENTLY ASKED QUESTIONS
================================================================
================================================================

-----------------------------------------------------------------
Q: How often should I fill observation forms?
-----------------------------------------------------------------
A: After EVERY lecture or lab session you observe. 
   Don't wait until end of day - submit immediately
   while details are fresh.

-----------------------------------------------------------------
Q: Can I edit a submitted form response?
-----------------------------------------------------------------
A: No, Google Forms doesn't allow editing after submission.
   If you made a mistake:
   1. Contact QC Lead
   2. They can edit the data directly in the sheet
   3. OR submit a new form with "CORRECTION:" in comments

-----------------------------------------------------------------
Q: Who can see the dashboard?
-----------------------------------------------------------------
A: Anyone with the link can view the dashboard.
   However, the data shown is only from your department.
   Individual instructor data requires login.

-----------------------------------------------------------------
Q: How long is data stored?
-----------------------------------------------------------------
A: Active data: Indefinitely in Google Sheets
   Resolved actions: Archived after 90 days
   Backups: Kept for 30 days

-----------------------------------------------------------------
Q: What if I make a mistake in the data?
-----------------------------------------------------------------
A: Contact QC Lead with:
   - Date of the entry
   - Which form/sheet
   - What needs to be corrected
   They will fix it directly in the sheet.

-----------------------------------------------------------------
Q: Can I access the system from my phone?
-----------------------------------------------------------------
A: Yes!
   - Google Forms: Works on mobile browsers
   - Dashboard: Works on mobile (may be smaller)
   - Sheets: Use Google Sheets app

-----------------------------------------------------------------
Q: How do I get technical help?
-----------------------------------------------------------------
A: 1. First, check Section 9 (Troubleshooting)
   2. If not solved, contact IT Support
   3. Provide:
      - What you were trying to do
      - What error you saw
      - Screenshots if possible

-----------------------------------------------------------------
Q: What happens if internet goes down?
-----------------------------------------------------------------
A: - Forms cannot be submitted offline
   - Dashboard won't load without internet
   - Keep paper forms as backup
   - Enter data when connection restored

-----------------------------------------------------------------
Q: Can I export data to Excel?
-----------------------------------------------------------------
A: Yes!
   1. Open Google Sheet
   2. File > Download > Microsoft Excel (.xlsx)
   3. Opens in Excel on your computer

-----------------------------------------------------------------
Q: Why isn't my data showing on dashboard?
-----------------------------------------------------------------
A: Possible reasons:
   - Form not connected to sheet
   - Dashboard cache (try hard refresh)
   - API URL not configured
   - Time delay (wait 2-3 minutes)
   See Section 9.3 for detailed troubleshooting.

SECTION 14: GLOSSARY
================================================================
================================================================

-----------------------------------------------------------------
API (Application Programming Interface)
-----------------------------------------------------------------
A way for different software to communicate.
In this system, the dashboard talks to Google Sheets via API.

-----------------------------------------------------------------
Audit Trail
-----------------------------------------------------------------
A record of who did what and when.
Apps Script logs keep track of all script executions.

-----------------------------------------------------------------
Backup
-----------------------------------------------------------------
A copy of your data saved for safety.
This system creates automatic daily backups.

-----------------------------------------------------------------
CORS (Cross-Origin Resource Sharing)
-----------------------------------------------------------------
A security feature that controls which websites can access data.
If you see "CORS error", the API needs reconfiguration.

-----------------------------------------------------------------
Dashboard
-----------------------------------------------------------------
A visual display showing key information at a glance.
Like a car dashboard, it shows important metrics.

-----------------------------------------------------------------
Deployment
-----------------------------------------------------------------
Making software available for use.
"Deploying" the Apps Script makes it accessible online.

-----------------------------------------------------------------
Form Response
-----------------------------------------------------------------
The data submitted when someone fills out a Google Form.
Each submission creates one row in the linked sheet.

-----------------------------------------------------------------
GitHub Pages
-----------------------------------------------------------------
Free website hosting service by GitHub.
We use it to host the dashboard.

-----------------------------------------------------------------
KPI (Key Performance Indicator)
-----------------------------------------------------------------
An important metric that shows how well something is performing.
Example: "Average Lecture Score" is a KPI.

-----------------------------------------------------------------
Repository
-----------------------------------------------------------------
A storage location for code and files on GitHub.
Like a folder for your project.

-----------------------------------------------------------------
Trigger
-----------------------------------------------------------------
An automation that runs code at specific times or events.
Example: "Weekly report trigger" sends email every Monday.

-----------------------------------------------------------------
Web App
-----------------------------------------------------------------
An application accessed through a web browser.
The dashboard is a web app.
