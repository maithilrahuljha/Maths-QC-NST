STEP 3: Name Your Spreadsheet

   c) Press Enter

STEP 4: Get Your Spreadsheet ID
---------------------------------
   Look at the URL in your browser:

                                          ↑↑↑↑↑↑↑↑↑↑↑
                                          THIS IS YOUR ID
   
   Copy this ID and save it. You'll need it later!

SECTION 3: CREATE 5 FORMS
================================================================

Create these 5 forms. Questions are FLEXIBLE - you can add,
remove, or modify them later without breaking the system!

3.1 HOW TO CREATE A FORM
-------------------------

STEP 1: Go to https://forms.google.com
STEP 2: Click "Blank" to create new form
STEP 3: Click "Untitled form" and type the name
STEP 4: Add questions (see below)

3.2 FORM 1: LECTURE OBSERVATION
-------------------------------

Name: Lecture Observation Form

QUESTIONS TO ADD:

Q1: "Observation Date"
    Type: Date
    Required: Yes

Q2: "Course Code"
    Type: Dropdown
    Options: MATH101, MATH102, MATH201, etc.
    Required: Yes

Q3: "Instructor Name"
    Type: Dropdown
    Options: Dr. Smith, Dr. Jones, etc.
    ⚠️ MUST match faculty email list exactly!
    Required: Yes

Q4: "Session Type"
    Type: Multiple Choice
    Options: Lecture, Lab, Tutorial
    Required: Yes

Q5: "Academic Correctness Score"
    Type: Linear Scale
    1 to 5 (1=Poor, 5=Excellent)
    Required: Yes

Q6: "Delivery Quality Score"
    Type: Linear Scale
    1 to 5
    Required: Yes

Q7: "Student Engagement Score"
    Type: Linear Scale
    1 to 5
    Required: Yes

Q8: "Board Work Quality Score"
    Type: Linear Scale
    1 to 5
    Required: Yes

Q9: "Pace Management Score"
    Type: Linear Scale
    1 to 5
    Required: Yes

Q10: "Strengths Observed"
     Type: Paragraph
     Required: No

Q11: "Areas for Improvement"
     Type: Paragraph
     Required: Yes

💡 TIP: Score columns MUST have "Score" or "Rating" in name!
   The script finds them automatically.

3.3 FORM 2: ASSESSMENT QC
-------------------------

Name: Assessment QC Form

Questions:
- Date
- Course Code (dropdown)
- Reviewer Name
- Assessment Type (Exam, Quiz, Assignment)
- Questions Reviewed (number)
- Quality Score (linear scale 1-5)
- Accuracy Score (linear scale 1-5)
- Coverage Score (linear scale 1-5)
- Final Decision (Pass, Needs Revision, Reject)
- Comments

3.4 FORM 3: RESEARCH QC
-----------------------

Name: Research QC Form

Questions:
- Date
- Project Title
- Student Names
- Faculty Mentor (dropdown - same as instructor list)
- Originality Score (linear scale 1-5)
- Methodology Score (linear scale 1-5)
- Analysis Score (linear scale 1-5)
- Presentation Score (linear scale 1-5)
- Status (In Progress, Complete, etc.)
- Comments

3.5 FORM 4: STUDENT FEEDBACK
----------------------------

Name: Student Feedback Form

Questions:
- Date
- Course Code (dropdown)
- Instructor Name (dropdown)
- Subject Knowledge Rating (linear scale 1-5)
- Teaching Clarity Rating (linear scale 1-5)
- Engagement Rating (linear scale 1-5)
- What's Working Well? (paragraph)
- Suggested Improvements (paragraph)

3.6 FORM 5: ACTION TRACKER
--------------------------

Name: Action Tracker Form

Questions:
- Date
- Issue Type (Academic, Delivery, Process, etc.)
- Severity (Critical, High, Medium, Low)
- Description (paragraph)
- Assigned To
- Target Date
- Status (Open, In Progress, Resolved)

SECTION 4: CONNECT FORMS TO SPREADSHEET
================================================================

This is the key step! Each form connects to the SAME spreadsheet.
Google automatically creates a tab for each form.

FOR EACH OF THE 5 FORMS:

STEP 1: Open the form (in edit mode)

STEP 2: Click "Responses" tab at top

STEP 3: Click the green Google Sheets icon

STEP 4: Select "Select existing spreadsheet"

STEP 5: Find and click "QC_System_Data"

STEP 6: Click "Select"

STEP 7: Google creates a new tab automatically!

REPEAT for all 5 forms.

After connecting all forms, your spreadsheet has:
┌─────────────────────────────────────────────────────┐
│                   QC_System_Data                    │
├─────────────────────────────────────────────────────┤
│ Tab: Lecture Observation Form (Responses)           │
│ Tab: Assessment QC Form (Responses)                 │
│ Tab: Research QC Form (Responses)                   │
│ Tab: Student Feedback Form (Responses)              │
│ Tab: Action Tracker Form (Responses)                │
│ Tab: Summary_Scores                                 │
│ Tab: Dashboard_Data                                 │
└─────────────────────────────────────────────────────┘

⚠️ Tab names are created by Google automatically.
   The script finds them by keywords (lecture, assessment, etc.)
   so exact names don't matter!

SECTION 5: ADD THE SCRIPT CODE
================================================================

5.1 OPEN APPS SCRIPT
--------------------

STEP 1: Open your QC_System_Data spreadsheet

STEP 2: Click "Extensions" menu

STEP 3: Click "Apps Script"

STEP 4: A new tab opens with script editor

STEP 5: Click "Untitled project" and name it:
        QC_Automation_System

5.2 CREATE SCRIPT FILES
-----------------------

You need 3 script files. Delete the default Code.gs first.

CREATE FILE 1: config
   a) Click "+" next to Files
   b) Select "Script"
   c) Name it: config
   d) Delete any default code

CREATE FILE 2: processor
   a) Click "+" next to Files
   b) Select "Script"
   c) Name it: processor

CREATE FILE 3: emailBot
   a) Click "+" next to Files
   b) Select "Script"
   c) Name it: emailBot

Delete the original Code.gs:
   a) Right-click Code.gs
   b) Select "Remove"

5.3 COPY CODE INTO FILES
------------------------

Open each file and paste the corresponding code from the
package provided. The files are in: public/scripts/

FILE: config.gs     → paste into "config"
FILE: dynamicProcessor.gs → paste into "processor"
FILE: emailBot.gs   → paste into "emailBot"

After each paste, press Ctrl+S to save.

SECTION 6: CONFIGURE YOUR SETTINGS
================================================================

Open the "config" file and update these values:

6.1 SPREADSHEET ID
------------------

Find this line:
   const SPREADSHEET_ID = '[YOUR_SPREADSHEET_ID]';

Replace with your ID:
   const SPREADSHEET_ID = '1aBcDeFgHiJkLmNoP';

6.2 YOUR EMAIL
--------------

Find this line:
   const LEAD_EMAIL = '[YOUR_LEAD_EMAIL]';

Replace with your email:
   const LEAD_EMAIL = 'you@university.edu';

6.3 FACULTY EMAIL LIST
----------------------

Find the FACULTY_EMAILS section and add your faculty:

const FACULTY_EMAILS = {
  "Dr. Smith": "smith@university.edu",
  "Dr. Jones": "jones@university.edu",
  "Prof. Williams": "williams@university.edu",
  // Add all your faculty here
};

⚠️ CRITICAL: Names MUST match EXACTLY what's in form dropdowns!

6.4 SAVE
--------

Press Ctrl+S to save changes.

SECTION 7: SET UP AUTOMATION TRIGGERS
================================================================

Triggers make the script run automatically.

7.1 OPEN TRIGGERS
-----------------

STEP 1: In Apps Script, click clock icon ⏰ (left sidebar)
STEP 2: Click "+ Add Trigger" (bottom right)

7.2 TRIGGER 1: FORM SUBMIT
--------------------------

This runs when ANY form is submitted.

Settings:
- Choose function: onFormSubmit
- Event source: From spreadsheet
- Event type: On form submit

Click "Save"

7.3 AUTHORIZE THE SCRIPT
------------------------

First time, you'll see authorization popup:

STEP 1: Click "Review permissions"
STEP 2: Select your Google account
STEP 3: Click "Advanced" (bottom left)
STEP 4: Click "Go to QC_Automation_System (unsafe)"
STEP 5: Click "Allow"

⚠️ "Unsafe" warning is normal for personal scripts.
   Google hasn't reviewed YOUR script - that's OK!

7.4 TRIGGER 2: WEEKLY SUMMARY
-----------------------------

Click "+ Add Trigger" again:

Settings:
- Choose function: sendWeeklySummary
- Event source: Time-driven
- Type: Week timer
- Day: Monday
- Time: 8am to 9am

Click "Save"

7.5 TRIGGER 3: MONTHLY REPORT (Optional)
----------------------------------------

Click "+ Add Trigger" again:

Settings:
- Choose function: sendMonthlyReport
- Event source: Time-driven
- Type: Month timer
- Day: 1
- Time: 9am to 10am

Click "Save"

SECTION 9: TROUBLESHOOTING
================================================================

PROBLEM: Form submitted but no data in sheet
SOLUTION:
□ Check form is connected to correct spreadsheet
□ Open form → Responses → Check Sheets icon shows connection
□ Reconnect if needed

PROBLEM: Score not appearing in Summary_Scores
SOLUTION:
□ Check trigger is set up (clock icon in Apps Script)
□ Check Executions log for errors
□ Verify column headers contain "Score" or "Rating"

PROBLEM: Email not received
SOLUTION:
□ Check spam folder
□ Verify faculty name in form matches FACULTY_EMAILS exactly
□ Check LEAD_EMAIL is configured
□ Run sendWeeklySummary() manually to test

PROBLEM: Script error
SOLUTION:
□ Check Executions log (left sidebar)
□ Verify SPREADSHEET_ID is correct
□ Verify all required settings are configured
□ Remove [brackets] from placeholder values

PROBLEM: Wrong tab detected
SOLUTION:
□ Tab name should contain keyword (lecture, assessment, etc.)
□ Check TAB_KEYWORDS in config matches your tab names
□ Rename tab to include keyword
