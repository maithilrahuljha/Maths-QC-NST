================================================================
SETUP STEPS (SIMPLIFIED)
================================================================

STEP 1: Create ONE Spreadsheet
------------------------------
1. Go to Google Sheets
2. Create new blank spreadsheet
3. Name it: QC_System_Data
4. Copy the Spreadsheet ID from URL

STEP 2: Create 5 Forms
----------------------
Create these forms (questions flexible):

Form 1: Lecture Observation
- Date, Course, Instructor
- Rating questions (1-5 scale)
- Comments

Form 2: Assessment QC
- Date, Course, Reviewer
- Rating questions
- Decision

Form 3: Research QC
- Project details
- Rating questions
- Status

Form 4: Student Feedback
- Course, Instructor
- Rating questions
- Comments

Form 5: Action Tracker
- Issue details
- Severity, Status
- Resolution

STEP 3: Connect Each Form to Spreadsheet
----------------------------------------
For EACH form:
1. Open form → Responses tab
2. Click Google Sheets icon
3. Select "Select existing spreadsheet"
4. Choose "QC_System_Data"
5. It creates a new tab automatically!

STEP 4: Add Script
------------------
1. Open QC_System_Data spreadsheet
2. Extensions → Apps Script
3. Paste the code
4. Update SPREADSHEET_ID
5. Save and authorize

STEP 5: Done!
-------------
- Forms submit to tabs
- Script processes data
- Emails sent automatically

  ASSESSMENTS: ['assessment', 'qc'],

// Script creates these tabs if they don't exist:
const AUTO_CREATE_TABS = ['Summary_Scores', 'Dashboard_Data'];

WHY KEYWORDS?
-------------
When you connect a form to spreadsheet, Google creates a tab like:
"Lecture Observation Form (Responses)"

The script finds it by searching for "lecture" keyword.
You don't need exact tab names!

================================================================
FORM CONNECTION PROCESS
================================================================

When you connect Form to Spreadsheet:

1. Open your form in edit mode
2. Click "Responses" tab
3. Click the green Sheets icon
4. Choose "Select existing spreadsheet"
5. Find and select "QC_System_Data"
6. Click "Select"
7. Google creates a new tab automatically!

Tab naming:
- Google names it: "[Form Name] (Responses)"
- Example: "Lecture Observation Form (Responses)"
- Script finds it by keyword "lecture"

================================================================
WHAT HAPPENS WHEN FORM IS SUBMITTED
================================================================

1. User fills form and clicks Submit
2. Data goes to the form's tab in spreadsheet
3. Script trigger fires (onFormSubmit)
4. Script reads the tab name
5. Script identifies form type by keywords
6. Script calculates score (sum of 1-5 ratings)
7. Script finds instructor/faculty name
8. Script sends email to that faculty
9. Script updates Summary_Scores tab

All automatic! No manual steps needed.

================================================================
TROUBLESHOOTING
================================================================

Q: Form created tab with weird name
A: That's OK! Script finds by keyword, not exact name.

Q: Script can't find the tab
A: Check tab name contains keyword (lecture, assessment, etc.)

Q: Multiple tabs match same keyword
A: Script uses first match. Rename tabs to be unique.

Q: Want to rename tabs
A: You can! Just keep a keyword in the name.
   Example: "Lecture QC Data" works (has "lecture")
